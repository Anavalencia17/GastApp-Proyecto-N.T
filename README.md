# GastApp-Proyecto-N.T

Descripción del Proyecto

GastApp es una aplicación diseñada para gestionar gastos personales.
Permite registrar ingresos, gastos y visualizar la información para llevar un mejor control financiero.

Este proyecto fue desarrollado como parte del curso Nuevas Tecnologías.

# Reglas de Colaboración

No hacer commits directos a main o develop.

Cada tarea debe tener su propia rama feature/.

Todos los cambios deben enviarse mediante Pull Request.

Los commits deben tener mensajes claros.
